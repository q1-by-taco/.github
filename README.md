## 🏛️ About Q1 by TACO

**Q1 by TACO** is an independent artificial intelligence engineering research and systems group based in Florianópolis, Santa Catarina, Brazil. We design and build open-source infrastructure for autonomous agent orchestration, context window optimization, and mathematical anti-hallucination guardrails (*Evidence-First*).

Led by **[Márcio Krefta](https://github.com/kreftamarcio)** (independent prompt engineer and AI specialist) in partnership with **TACO Assessoria**, our work is purely community-driven. We are not employees of Google and hold no corporate partnerships or commercial agency relationships with Google LLC.

## 🔬 Core Technical Invariants

1. **Prefix-Stable Caching:** Structuring system ontologies and MCP schemas to guarantee **> 85% cache hit rates** on Google Gemini and Anthropic Claude, reducing inference latency by up to 73%.
2. **Delimiter Cryptography:** Enforcing strict semantic boundaries (`<untrusted_payload>`, `<context_contract>`) to render systems mathematically immune to indirect prompt injection.
3. **Evidence-First Verification:** Zero completion assertions without automated test proofs, AST diff validations, or deterministic runtime outputs.
4. **Universal MCP Protocol:** Decoupled JSON-RPC 2.0 tool buses replacing proprietary, brittle SDK wrappers.
